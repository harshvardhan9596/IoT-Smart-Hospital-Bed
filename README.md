# IoT-Based Smart Hospital Bed and Patient Movement Tracking System

An IoT-based smart healthcare monitoring system developed using ESP32
to monitor patient presence, movement, temperature and emergency conditions.

## Features

- Patient presence detection
- Patient movement detection
- Fall detection
- Body temperature monitoring
- Real-time web dashboard
- Emergency LED alerts
- Voice alerts
- Wi-Fi-based communication
- Live sensor data visualization

## Hardware

- ESP32
- IR Sensors
- MPU6050 Motion Sensor
- LM35 Temperature Sensor
- LED
- Resistors
- Jumper Wires
- PCB / Perfboard

## Software

- C/C++
- Arduino IDE
- HTML
- CSS
- JavaScript
- ESP32 WebServer
